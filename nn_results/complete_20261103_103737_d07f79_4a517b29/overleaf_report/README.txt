Upload OVERLEAF_REPORT.zip as an Overleaf project and compile main.tex with pdfLaTeX. Edit results.tex for the report body, captions, and figure calls. The overleaf_figures folder contains descriptive stable filenames. To use your existing report, copy results.tex and overleaf_figures into that project, add graphicx, float, booktabs, longtable, amsmath to its preamble, then input results.tex where required. Alternatively copy individual figure calls. The appendix includes remaining saved figures. Re-exporting regenerates the local LaTeX files; preserve your own edits separately. No training or simulation is started by this exporter.
